# OLADIMEJI OGUN & CO. — Interactive Law Firm Website

A modern, responsive HTML5/CSS3/Vanilla JavaScript law-firm website.

## Included
- Multiple pages
- Responsive navigation
- Interactive practice-area filters
- Scroll reveal animations
- Animated counters
- FAQ accordions
- Rotating testimonial/experience slider
- Legal insight/resource cards
- Timeline / process section
- Interactive demo forms with validation feedback
- Back-to-top control
- Mobile-friendly layout
- External CSS and JavaScript
- Local images/assets

## GitHub Pages
1. Extract this ZIP.
2. Upload the contents into the root of a public GitHub repository.
3. Go to Settings → Pages.
4. Choose Deploy from branch → main → / (root).
5. Save and wait for GitHub Pages to publish.

## Important
The contact/booking forms are front-end demo forms. They do not send email or store submissions on a server.
